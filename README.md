# Manage-User-data-rest-API-
📌 Flask User CRUD API

A simple and beginner-friendly REST API built using Flask.
It supports full CRUD operations (Create, Read, Update, Delete) for users stored in in-memory data.
You can test the API using Postman, Thunder Client, Curl, or a browser.

# 🚀 Features -

🟢 GET all users

🔵 GET a single user by ID

🟡 POST add new user

🟣 PUT update user

🔴 DELETE remove a user

🖥️ HTML page using render_template()

⚡ No database required (in-memory list)
